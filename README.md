# 🎬 CineVerse

A responsive, feature-packed Move and TV show showcase site built with React, Vite, and Tailwind CSS.


## 🛠️ Technology Stack

- **Core Framework:** React 18
- **Build Tool:** Vite
- **Routing:** React Router 
- **Styling:** Tailwind CSS 4.3.3 
- **Icons:** Lucide React
- **API Source:** [TVMaze API](https://www.tvmaze.com/api)
  - All Shows: `GET https://api.tvmaze.com/shows`
  - Search Shows: `GET https://api.tvmaze.com/search/shows?q=:query`


### Installation & Local Setup

1. Navigate to the project directory:
   ```bash
   cd movie-explorer
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`.
